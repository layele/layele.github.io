# 山水墨画 · 双世界交互式个人网站（最新版）

## 目录说明

- `index.html`：标准部署版入口（引用 `assets/` 文件夹高清原图，适合上传至 Vercel、Netlify、Cloudflare Pages 或 GitHub Pages）
- `standalone-preview.html`：单文件离线版（已内置压缩画卷，双击即可在任意浏览器离线打开）
- `assets/`：四季实体山水画卷（春桃/夏青/秋枫/冬雪）、凌云古塔室内、云端书案、AI 科技图书馆及各场景高清素材

## 核心功能一览

1. **四季实体山水与流动水体**：右下角自由切换春夏秋冬真实景致与气候粒子，配合顶部「晨雾 / 夜墨灯火」与五声古琴微音效。
2. **六景沉浸交互与所见即所得直接编辑**：进入凌云古塔（案头宣纸引首与引言）、重檐楼阁、飞瀑石桥、翠竹幽径、苍松石阶、烟波孤舟，所有文字均可直接点击改写并自动保存在本地浏览器。
3. **云端工作台（镜头推进 · 拨云见案）**：桌面宣纸展示可编辑引言与引首任务，其余任务以独立线装书陈列案前，支持待办/已完成/重难点划分与直接编辑。
4. **左衔接 3D 反转 · AI 科技图书馆**：点击画卷最左侧入口翻转进入科技风图书馆，含已读书架、未读书架与中央研读桌。
